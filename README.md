# Networking Projects

A collection of Cisco Packet Tracer networking labs and configuration exercises.

## Topics covered
- Network topology design.
- IP addressing and subnetting.
- Router and switch configuration.
- VLAN and basic network segmentation practice.
- Connectivity testing and troubleshooting.

## Tools
- Cisco Packet Tracer.
- Basic networking and TCP/IP concepts.

## How to use
1. Download and install Cisco Packet Tracer.
2. Open a `.pkt` lab file from this repository.
3. Review the topology and configuration objectives.
4. Test connectivity and inspect the device configurations.

These labs document practical networking study and troubleshooting exercises.
